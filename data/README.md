# Data

The raw ICIJ Offshore Leaks CSV files are too large to store in this GitHub repository.

They can be downloaded from the ICIJ Offshore Leaks Database:

https://offshoreleaks.icij.org/pages/database

A backup copy for this project is stored in Google Drive:

https://drive.google.com/drive/folders/1E2QqiSWAmhHTxA-xARmLqjtWlK7xQsgU?usp=sharing

To reproduce the analysis, download and unzip the data, then place the files locally in:

data/raw/full-oldb.LATEST/

Expected files:

- nodes-entities.csv
- nodes-officers.csv
- nodes-addresses.csv
- nodes-intermediaries.csv
- relationships.csv
- nodes-others.csv
